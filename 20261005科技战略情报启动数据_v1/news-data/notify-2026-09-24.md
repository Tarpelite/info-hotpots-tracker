## 🔥 美国能源部发布量子创世纪竞赛，资助部署首个科研级容错量子算力
**来源**: Grants.gov 资助公告

- **国家级容错量子计算推进**：美国能源部（DOE）依据推进前沿量子创新的总统行政令，正式启动 **Quantum Genesis** 计划及配套的 **Q 竞赛**（Q Competition），重点资助开发并部署全球首套面向前沿科研的容错量子计算能力（SRQC）。
- **绑定国家实验室科研工作流**：该项目要求入选伙伴不仅要交付第一代科研级容错整机，还需完成与国家实验室实际科研工作流的软硬件适配，并为 2030 年代在国家实验室体系内规模化部署下一代 SRQC 确立技术基准。

该竞赛跳过了传统的概念验证与含噪中等规模量子（NISQ）示范，直接把联邦资助重心锚定在与国家实验室具体科研任务深度耦合的容错级算力整机交付上。

[Grants.gov 资助公告](https://simpler.grants.gov/opportunity/05ea4b35-7c9b-45a7-98cb-7579ac2c0b19)

## 🔥 Anthropic 设立分子生物实验室，Claude 挖掘出未知类 CRISPR 噬菌体酶系统
**来源**: Anthropic

- **发现新型可编程特征酶系统**：Anthropic 披露其团队利用 Claude 在噬菌体 DNA 中识别出一类此前未知的酶系统。该酶基因侧翼分布有长串重复 DNA 序列，结构与 CRISPR 高度相似；自然界中已知具备同类特征的少数系统均具备对 DNA 的切割、复制与修剪能力。
- **自建湿法实验室验证闭环**：该发现是 Anthropic 新设分子生物学湿法实验室的首个研究成果。工作流由 Claude 解析文献与测序数据生成科学假说并筛选候选生物系统，再由 Anthropic 内部实验科学家执行湿实验验证。
- **开放外部前沿课题合作**：Anthropic 表示正将这套由模型驱动假说生成、人类科学家落地的科研范式向全基因组学及其他基础生物学领域铺开，并向外部研究团队开放课题合作征集。

AI 研发机构正在跳出纯计算辅助的传统外包模式，通过自建湿法实验室打通“大模型假说生成-内部物理实验验证”的密集反馈链路；该成果证实通用大模型已具备直接从未标注的天然基因序列中自主筛选具备可编程编辑特征系统的挖掘能力。

[Anthropic 官博](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system) | [Anthropic 官方推文](https://x.com/AnthropicAI/status/2102824959827742916)

## 🔥 英伟达与DeepMind联合开源2800种病毒蛋白质复合体结构数据集及加速管线
**来源**: NVIDIA 官方博客

- **超两千种病毒复合体数据全量开放**：英伟达联合 Google DeepMind 及欧洲生物信息学研究所（EMBL-EBI）等机构，在 AlphaFold 数据库中公开了超过 **2,800 种病毒**的蛋白质复合体三维结构预测数据。其中约 **30% 的蛋白相互作用形态**在蛋白质数据库（PDB）中从未被记录。
- **开源 GPU 高通量预测管线**：数据通过 **AlphaFold2** 与 **NVIDIA BioNeMo Inference Runtime** 进行软硬件深度优化生成，将原本需耗时数年的晶体解析大幅压缩至分钟级；英伟达同步在 GitHub 开源了完整的端到端 GPU 加速工作流 **BioNeMo Structure Prediction Pipeline**。
- **覆盖全量人类感染病毒家族**：预测覆盖了从常见呼吸道病毒到猴痘（Mpox）等已知感染人类的高危病毒全谱系，系统性填补了以往研究中绝大多数病毒缺乏高阶多蛋白互作三维表征的数据真空。

该工作将 AI 结构预测的边界从孤立单体蛋白推进至病毒组尺度的“多聚复合体”互作网络，配合开放的端到端推理管线，使应对未知病原体的结构解析从被动、高成本的物理实验转变为可预先计算的高通量数字储备库。

[NVIDIA 官方博客](https://blogs.nvidia.com/blog/open-protein-dataset/) | [BioNeMo Pipeline GitHub 仓库](https://github.com/NVIDIA-BioNeMo/BioNeMo-Structure-Prediction-Pipeline) | [AlphaFold 数据平台](https://alphafold.ebi.ac.uk/)
